# Oracle of Tantra — Architecture Notes

## Product modes

- Guest Oracle: no account, introductory research and exploration.
- Personal Oracle: Google/email authentication, private conversations, bookmarks, notes, collections and optional personalization.
- Researcher: focused reading/search workspace with minimal animated library background and Kindle-like focus mode.

## Evidence model

Important answers should distinguish:

1. Textual evidence
2. Historical scholarship
3. Traditional interpretation
4. Modern interpretation
5. AI synthesis

## Source lifecycle

User submission → evidence form → pending review → admin verification → rights/licence check → approved source record → optional ingestion into the knowledge base.

Uploaded user documents are private by default. They are never automatically added to the public corpus. A user must explicitly submit a document for review before it can be considered for ingestion.

## Copyright principle

Public-domain and appropriately licensed material may be stored when legally permitted. Restricted copyrighted works should be represented with bibliographic metadata and links to lawful access rather than copied into the public corpus.

## Frontend direction

The entrance is deliberately atmospheric and Bengali folk-art / patachitra-inspired. The researcher workspace is intentionally calmer: a subtle animated library, readable typography, source panels and a distraction-free reading mode.
